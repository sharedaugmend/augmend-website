## STYLE ANCHOR (paste at the start of every generation session)

```
STYLE: A visualization made of different densities of deep indigo blue points on a very dense, very fine regular grid. The points sit on a creamy frosted glass surface — they blend into the surface as if they merge from it with depth and density. Dot size defines the subject: larger dots where the subject is dense, shrinking to the point of disappearing in empty areas. The background grid of tiny dots is always faintly visible even in empty space. The dots have a subtle three-dimensional quality, like raised pins on a frosted surface. Warm cream-white background. Minimal, clinical, precise. Very fine grid — small dots, closely spaced, hundreds across the image width.
```

## PROMPT OPTIMIZATION NOTES

### For Nano Banana Pro
1. Lead with "A visualization of [subject] made of different densities of points."
2. Include "the points are on a very dense, very fine regular grid" — without this, grids are too coarse.
3. Include "creamy frosted glass" for the surface.
4. Describe colors ("deep indigo blue") not hex codes.
5. Keep prompts under 120 words for core subject. Add a second shorter paragraph for dissolution/detail behavior.
6. Generate IMG-02 (hand) first, iterate for density, use as style reference for everything else.
7. For data visualization prompts (IMG-05, 09, 15): reference "scatter plot density" — thousands of tiny dots creating patterns.

### For Veo 3.1
1. Always start with "Stationary camera, no movement" (unless you want camera motion).
2. Describe grid state at start AND end for loops.
3. One motion concept per video.
4. 3-5s clips are more controllable than 10s+.
